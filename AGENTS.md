## 3. Strict TypeScript & Coding Guardrails
- **Zero `any` or `@ts-ignore`:** The `tsconfig.json` enforces `"strict": true`, `"noImplicitAny": true`, and `"noUncheckedIndexedAccess": true`. Using `any`, `as unknown as T`, or `@ts-ignore` is strictly forbidden.
- **Mandatory Explicit Return Types on Server Functions:** Every Server Action in `src/server/actions/*` must explicitly declare `Promise<ActionResponse<T>>` as its return type.
- **Integer Kobo Enforcement:** Never perform floating-point multiplication on Naira values in client or server code. All monetary inputs and database writes must use integer kobo (`100 kobo = ₦1.00`) and pass through `src/lib/money.ts`.
- **Next.js 15 Async Request APIs:** In Next.js 15, `params`, `searchParams`, `cookies()`, and `headers()` are asynchronous Promises. Always `await` them (`const { slug } = await params;`).
- **Redirect Rule for `/mtn-fibrex`:** Ensure `next.config.ts` configures a permanent redirect (`308`) from `/mtn-fibrex` to `/mtn-services/fibrex` (or vice versa) so both URLs referenced in the client brief resolve seamlessly.

## 5. Autonomous Self-Verification Loop
After completing any code edit, migration update, or component implementation, you MUST execute the following verification pipeline in the Antigravity terminal before reporting completion to the user:

```bash
pnpm typecheck && pnpm lint && pnpm test:unit
```

If any command emits a warning or error:
1. Inspect the exact stack trace and line number.
2. Fix the root cause without weakening TypeScript types or disabling ESLint rules.
3. Re-run `pnpm typecheck && pnpm lint && pnpm test:unit` until all checks exit with code `0`.
